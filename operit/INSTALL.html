在 Operit 中安装「棋院」

方式一（推荐）：Operit 内置浏览器打开

本仓库开启 GitHub Pages 后，把首页地址（如 https://your-name.github.io/operit-chess-arena/）在 Operit 内置浏览器中打开即可。应用会自动接入 Operit 的 AI，聊天面板能「看棋盘说话」。

方式二：作为 ToolPkg 导入

进入 Operit 市场/工具箱 → 导入本地包，选择本仓库 operit/ 目录。导入后出现工具 chess_arena_open 与 chess_arena_ask。

接 AI 的要点

  1. 棋类页右侧「聊天」随时问 AI，它看得到当前局面。
  2. 「设置」填 OpenAI 兼容 Base URL / Key / Model（Operit 内可复用已配模型）。
  3. 勾「大模型执子」：AI 亲自下并解说；不勾则由内置启发式 AI 对弈。

详细见 INSTALL.md。仓库：operit-chess-arena
